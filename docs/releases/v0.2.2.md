A fix release for solo mode's build hat.

## Upgrade

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/ryter/main/install.sh | sh
```

## Fixes

**Build could sit on "thinking" forever after a long reply.** A model that drafts code in its reasoning could use up the whole reply, 8,192 tokens, before writing anything. The reply came back empty, and because solo turns never told the screen they had ended, it kept showing "thinking". There were three problems, all fixed:

- **Output limit:** each reply now has room for 32,768 tokens, the same as crew builders. You pay only for tokens actually generated.
- **Cut-off replies:** a reply cut off at the limit is recovered instead of ending the turn. The model is told to carry on in smaller steps and to write code straight to files, not into its reasoning. After three cut-offs in a row the turn stops and says why.
- **"Thinking" forever:** every solo turn now tells the screen when it starts and ends, even when it switches hats partway through.

The build prompt also tells the model not to draft code in its reasoning.

If a session is stuck like this: upgrade, run `ryter resume`, and say "continue".
