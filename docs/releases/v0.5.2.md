`/undo` puts back what the last build turn changed, and only that. Your own edits stay, and `/redo` reverses an undo.

## Upgrade

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/ryter/main/install.sh | sh
```

## What was wrong

`/undo` reset the whole project to the snapshot taken before the last build turn. If you edited a file or created one between turns, in your editor, while you read what the model had done, `/undo` reverted your edit and deleted your file along with the model's changes. There was no way to get them back.

A gitignored file the model overwrote, such as a local config, couldn't be undone at all. `/undo` said "nothing to undo".

## What changed

- **`/undo` puts back only the files that turn changed.** Ryter now snapshots at the end of each build turn as well as the start, so it knows which files were the turn's. Everything else stays as you left it.
- **It won't undo over your own edits.** If you've changed one of the turn's files since, `/undo` leaves everything alone and names the file. `/undo force` goes ahead.
- **`/redo` reverses an undo,** forced or not, until the next build turn. It asks for `/redo force` if you've edited those files since the undo.
- **Gitignored files the model writes are saved first,** so `/undo` puts them back too. A file changed by a shell command isn't covered.
- **A file undone in `/changes`** (`x`) is brought back by `/undo` on its own, without touching anything around it.

Sessions started before 0.5.2 still undo their older turns the old way, since there's no end snapshot for them. `/redo` can reverse those now.

## Tried before release

In the TUI, on `deepseek-v4.1-flash`:

1. **The model added `median` to `stats.js`.** Then, by hand, I added a note to `NOTES.md`.
2. **`/undo`:** `put back 1 file (stats.js)`. `median` was gone and my note in `NOTES.md` stayed. Before 0.5.2 the note would have been lost.
3. **`/redo`:** `redone: stats.js`, and `median` was back.
4. **I added a comment to `stats.js` by hand, then `/undo`:** `not undone: you changed stats.js since that turn…`, and nothing changed.
5. **`/undo force`:** it undid, over my comment. **`/redo`** brought back `median` and my comment.
