Spend counts what you pay. Claude's prompt caching is priced correctly on a direct Anthropic connection. A budget now stops a model it can't price instead of letting it run uncapped. A crew task's cap counts every run.

## Upgrade

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/ryter/main/install.sh | sh
```

## What was wrong

- **Anthropic spend showed about half.** On a direct Anthropic connection, the cost of writing to Claude's prompt cache (1.25× input) wasn't counted at all. The cached part of the prompt was also subtracted from a count that had already left it out. The context gauge was off the same way: a 100k-token prompt showed as about 2k.
- **A budget didn't apply to a model with no price.** If Ryter had no price for a model and the provider didn't report one, spend showed `$?.??` and the budget never stopped it.
- **A crew task's cap started over each run.** A task that was retried across runs was never capped as a whole.

On OpenRouter, the provider reports each call's cost, so spend there was already right.

## What changed

- **Prompt caching is priced in parts:** cache reads at the cached rate, cache writes at the cache-write rate, and the rest at the input rate. OpenRouter's cache rates are read from its catalog. For other providers, give them in `[pricing]` in `config.toml`:

  ```toml
  [pricing."claude-sonnet-5"]
  input_per_million = 3.0
  cached_per_million = 0.3
  cache_write_per_million = 3.75
  output_per_million = 15.0
  ```

- **With a budget set, a model with no price is stopped after one call.** The reply that came back is kept, and Ryter tells you the budget can't see that model's cost. The next message doesn't call it: Ryter says to give the model a price or turn the budget off (`/budget off`). Headless (`ryter -p`) exits `3`, as for any budget stop. Without a budget, nothing changes.
- **A crew task's caps (`task_budget_usd`, `task_max_tokens`) count every run of that task.**

## Tried before release

Against a local mock provider, with a $5 budget:

1. **A model with no price.** The first message got its answer, followed by `mock-chat has no price, so the $5.00 budget can't see what it costs…`. The second message showed the stop and made no call; the mock logged one request in all. After `/budget off`, the third message went through.
2. **A Claude-style response with 90k cached tokens and 8k cache-write tokens,** priced at Claude Sonnet rates. Spend showed `$0.08`, which matches the math; before, it would have shown `$0.04`. The context gauge showed `101k / 200k`.
3. **Headless:** the same stop exited `3`, and the notice printed on its own line.
