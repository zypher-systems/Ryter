Anthropic and OpenAI are built in beside SpaceXSI and OpenRouter, SpaceXAI goes by its new name, and a current Claude model works on the Anthropic wire.

## Upgrade

```sh
ryter update
```

Coming from 0.30.0:

- **Four built-in connections.** `anthropic` (Messages API, `ANTHROPIC_API_KEY`, `claude-opus-5-5`) and `openai` (Responses API, `OPENAI_API_KEY`, `gpt-6.1-sol`) sit beside `spacexsi` and `openrouter` in `/provider`, `doctor`, `ryter connections` and `--connection`. Export the key, or `k` on the row, and the connection is live; no base URL to type. `openai_compat` stays the kind for any other server speaking chat completions, and no longer presumes a model.
- **SpaceXAI is SpaceXSI.** The kind, the built-in's name and the docs follow the company's new name. A config, a hat row, a saved session or a key that still says `spacexai` keeps working: the row takes the built-in's place, the old kind reads as the new, and a key saved as `keys/spacexai` is found until one is saved under `spacexsi`. The API host and `XAI_API_KEY` did not change.
- **Claude 4.6 and later think.** The Anthropic wire sent a thinking token budget, which Claude 4.6 and every later model reject with a 400. Those models now get `thinking: adaptive` at the reasoning level you chose; older Claude models keep the budget. OpenAI gets the reasoning level the way OpenRouter does.
- **Prices and windows for the new built-ins.** Claude and GPT models are priced from the providers' pages of 2026-10-19, with OpenAI's long-context tier past 272k tokens and Haiku 5.5's past 100k; Claude 4.6+ and GPT-6 have their million-token windows in the context gauge. The Grok table gains grok-4.7. A model the tables don't know still shows `$?.??`.

## Why

A reviewer or a new user should find the three labs and OpenRouter in `/provider` and be running on a pasted key. The rename follows the company; the alias exists because a renamed kind without one would have failed every saved config at startup.

## Good to know

- No live request to Anthropic or OpenAI was made before this release; the wire shapes are tested against the documented request bodies. A turn on each with your own key is the first thing to try.
- A cache write on a Claude 5 model is billed as plain input where Anthropic's page gives no rate for it, so a long cached session may read slightly under.
- The two 80-column edges from 0.30.0 are still there: the top bar's title runs into the status text, and the hint bar never shows `^c` or `esc`.
