
Coming from 0.28.0:

- **Model check when a hat's model is chosen (#85).** `/models` sends one tiny tool-bearing request when you pick a model for a hat, so a data-policy refuse, missing tools, or empty credits show up then — not on the first real message.
- **G4 — project blast (#86).** `tmux` kills are scoped to the session Ryter started; a delete under scratch also looks *below* the path, so a nested repository is protected.
- **G6 — cost truth (#87).** The context gauge uses the provider's `input_tokens`. Round-cap and budget stops share one voice and say how to go on.
- **G5 — curl headers ask (#88).** Headers, `-u`, user-agent, referer, and `-w` that expand a variable or look like a secret count as leaving the machine, same as a body.
- **Hats language (#89).** On disk: `[model]` / `[hats.*]` (old `[orchestrator]` / `[specialists.*]` still load). In code: `Role::{Plan,Build,Audit,Scribe}` and `Config::all_hats` / `hats`.
- **Streamed bash in the conversation (#90).** Running shell output updates the tool row live (`ToolLive`); it is not written to `events.jsonl`.
- **`/permissions` panel MVP (#91).** Browse and add rules from the TUI; card `r` can add a rule after an ask.
- **Anthropic thinking + tools (#92).** Thinking blocks are echoed back on Messages tool rounds so extended thinking keeps working across tool use.
