A new screen: **the ledger**. Your conversation reads as one column on a timeline. Each turn closes with what it did and what it cost, finished turns fold to a line, and one bar at the bottom carries the mode, the model, the context, and what you've spent. The 0.5 screen is still there as `layout = "classic"`, one setting away.

- **A timeline.** Each question starts with its time. The model's text, each tool step, and each edit hang off one line down the left. Tool steps are led by dots to what came of them: `+9 −1`, `✓ 4 passed`, `new · 6 lines`. Edits show as full-row green and red diffs, as before.
- **Every turn closes with what it came to**: tools used, files changed, lines added and removed, commands that passed or failed, how long it took, and what it cost. Ryter measures all of it; it isn't the model's account of its own work.
- **Finished turns fold to one line**, so scrolling back reads like a table of contents. `^O` opens them all, with every edit whole, and folds them again.
- **One reading column,** centered and at most about 100 columns of text, however wide your terminal is.
- **One bar at the bottom.** It shows the mode, the project and branch, the model, how full the context is, and the cost this turn, this session, and for the whole project, against your budget, with the keys that matter now. When the terminal is narrow it drops the keys first, then the project, the model, and the gauge. The mode and the costs stay.
- **`$` opens the spend drawer** when the message box is empty. It shows this turn, the session, and the project side by side, spend by role, and the budget, task cap, and warning level. `b` sets a budget, and `⏎` opens the full `/spend` table. A `$` typed in a message is still a dollar sign.
- **Small costs are shown as they are.** A turn that costs a fraction of a cent shows `$0.004` or `<$0.001` instead of `$0.00`.

## Going back

`/settings` → `layout` → `classic`, and the 0.5 screen is back at once: the header, the info cards on the right, the boxed composer, and the hint bar. It's saved as `[ui] layout = "classic"` in `~/.ryter/settings.toml`. `^B` still shows the info cards on the ledger.

## Tried before release

In the TUI, on `deepseek-v4.1-flash`, on a small JavaScript project:

1. **"What does mean() return for an empty array?"**, then **"Make mean() return 0 for an empty array, add a test, run npm test."** The first turn folded to one line with its summary. The second ran on the timeline: two edits with their diffs, `npm test ✓ 2 passed`, and the closing line `✓ 5 tools · 2 files (2 changed, +3 −0) · 1 command (1 ok) · 7.9s · $0.001`.
2. **`$`** opened the spend drawer, and Esc closed it.
3. **`^O`** opened the folded turn and folded it again.
4. **`/settings` → layout → classic** brought back the 0.5 screen at once and saved it. Switching back to `ledger` worked the same way.
