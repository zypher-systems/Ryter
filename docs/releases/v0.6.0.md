A new screen in three parts:
- **The ledger:** your conversation as one column on a timeline, each turn closed with what it did and cost, and one bar at the bottom for the mode, model, context, and spend.
- **Mission control:** crew mode's live board of the plan and the workers.
- **The workbench:** what changed, beside the chat, undoable one change at a time.

The 0.5 screen is still there as `layout = "classic"`, one setting away.

## Upgrade

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/ryter/main/install.sh | sh
```

## The ledger

```
      ·  welcome · /help for keys
13:14 ●  What does mean() return for an empty array? ········· ✓ 2 tools · 1.7s · <$0.001  ▸

13:14 ●  Zypher
      │  Make mean() return 0 for an empty array, add a test, run npm test.
      │
      ◆  deepseek-v4.1-flash
      │  Returning early on an empty array rather than special-casing the division.
      ├─ edit   stats.js ··································· +1 −0  1.4s
      │    2 +   if (xs.length === 0) return 0
      ├─ run    npm test ······························ ✓ 2 passed  3.9s
      ◆  Both tests pass.
      └─ ✓ 5 tools · 2 files (2 changed, +3 −0) · 1 command (1 ok) · 7.9s · $0.001
──────────────────────────────────────────────────────────────────────────────────
› what should change?
 BUILD  ltest  master  deepseek-v4.1-flash  ctx ▱▱▱▱ 0% │ turn $0.001 · session $0.001 · project $0.001 · budget off   $ spend
```

- **A timeline.** Each question starts with its time. The model's text, each tool step, and each edit hang off one line down the left. Tool steps are led by dots to what came of them: `+9 −1`, `✓ 4 passed`, `new · 6 lines`. Edits show as full-row green and red diffs, as before.
- **Every turn closes with what it came to**: tools used, files changed, lines added and removed, commands that passed or failed, how long it took, and what it cost. Ryter measures all of it; it isn't the model's account of its own work.
- **Finished turns fold to one line**, so scrolling back reads like a table of contents. `^O` opens them all, with every edit whole, and folds them again.
- **One reading column,** centered and at most about 100 columns of text, however wide your terminal is.
- **One bar at the bottom.** It shows the mode, the project and branch, the model, how full the context is, and the cost this turn, this session, and for the whole project, against your budget, with the keys that matter now. When the terminal is narrow it drops the keys first, then the project, the model, and the gauge. The mode and the costs stay.
- **`$` opens the spend drawer** when the message box is empty. It shows this turn, the session, and the project side by side, spend by role, and the budget, task cap, and warning level. `b` sets a budget, and `⏎` opens the full `/spend` table. A `$` typed in a message is still a dollar sign.
- **Small costs are shown as they are.** A turn that costs a fraction of a cent shows `$0.004` or `<$0.001` instead of `$0.00`.

## Mission control (crew mode)

Once the crew has a plan, a board sits above the lead's conversation:

```
╭ SPEND ─────────────╮ ╭ TASKS ─────────────╮ ╭ PATCH ─────────────╮ ╭ TIME ──────────────╮
│ $0.059 of $3.00    │ │ 1 of 3 landed      │ │ patch-1 → master   │ │ 0:32               │
╰────────────────────╯ ╰────────────────────╯ ╰────────────────────╯ ╰────────────────────╯
╭ PLAN ────────────────────────────────────╮ ╭ LANES ────────────────────────────────────╮
│ ✓ scaffold  landed                       │ │ auditor  ⠦ greet   reviewing (glm-5.3)  0:04 │
│ ├▶ ◑ greet  in audit 0:04                │ │ builder  ⠦ count   cargo build          0:04 │
│ └▶ ◐ count  building 0:04                │ │                                           │
╰──────────────────────────────────────────╯ ╰───────────────────────────────────────────╯
```

- **The plan is drawn from the task queue itself,** not from anything a model says. Each task sits under what it waits on, and each is marked `✓` landed, `◐` building, `◑` in audit, `✕` blocked, `○` waiting, or `◇` waiting for your go-ahead. A blocked task shows why, in full: `✕ scaffold  blocked: … sudo dnf install alsa-lib-devel`.
- **One lane per worker:** who is acting (the builder, or the auditor reviewing its work), on which task, what it is doing, and for how long.
- **Tiles:** spend against your budget, how many tasks have landed, what the patch is waiting on, and the crew's time and model calls this turn.
- **What each builder and auditor did is kept** in the session's `activity.jsonl`. Before, a builder's work left no trace but its bill.

## The workbench

`^T` (or `/changes`) opens the workbench:

- **Left:** the files changed this turn (or since the last commit, with `tab`), the commands the turn ran and what came of them, and the turns.
- **Middle:** the chat.
- **Right:** the selected file's changes, one at a time, with line numbers on both sides and green and red rows.

The keys:
- `↑↓` picks a file, and `j`/`k` moves between its changes.
- **`x` undoes just the selected change** and keeps the file's other changes.
- `X` undoes the whole file (it asks first), and `u` undoes the turn.
- `x` and `X` can themselves be undone with `/undo`.

While the workbench is open, keys go to it and not to the message box; `esc` or `^T` goes back to the chat.

## Going back

`/settings` → `layout` → `classic`, and the 0.5 screen is back at once: the header, the info cards on the right, the boxed composer, and the hint bar. It's saved as `[ui] layout = "classic"` in `~/.ryter/settings.toml`. `^B` still shows the info cards on the ledger.

## Tried before release

In the TUI, on `deepseek-v4.1-flash`. The ledger, on a small JavaScript project:

1. **"What does mean() return for an empty array?"**, then **"Make mean() return 0 for an empty array, add a test, run npm test."** The first turn folded to one line with its summary. The second ran on the timeline: two edits with their diffs, `npm test ✓ 2 passed`, and the closing line `✓ 5 tools · 2 files (2 changed, +3 −0) · 1 command (1 ok) · 7.9s · $0.001`.
2. **`$`** opened the spend drawer, and Esc closed it.
3. **`^O`** opened the folded turn and folded it again.
4. **`/settings` → layout → classic** brought back the 0.5 screen at once and saved it. Switching back to `ledger` worked the same way.

The workbench, after a turn that changed `stats.js` and `stats.test.js` and ran `npm test`:

1. **`^T`** showed both files with their counts, `npm test ✓ 4 passed` under commands, and `stats.js`'s change with line numbers.
2. **`x`** put `stats.js` back as it was and kept the test file's change. The workbench reloaded on its own.
3. **`u`** brought the change back, and **Esc** returned to the chat.

Mission control, on a crew run in a new Rust project, with a scaffold and two tasks after it (`glm-5.3-prime` as auditor):

1. **The board showed** the scaffold running, then `✓ scaffold landed`, with `greet` and `count` beneath it. Mid-run, `greet` was in audit and `count` was building, and the lanes showed the auditor reviewing and the builder running `cargo build`.
2. **At the end:** `3 of 3 landed`, the patch on `master`, and `cargo test` passing all 6 tests. The run cost $0.075.
