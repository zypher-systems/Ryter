## The fix

Ryter sent no reasoning setting to OpenRouter, and for some models that means unlimited thinking. I measured it with glm-5.3-flashx on a real build plan:

| Reasoning setting | Time to first file write | Reasoning first |
| --- | --- | --- |
| none (0.2.2) | 191 seconds | ~27,000 tokens |
| `medium` (0.2.3 default for build) | 7 seconds | none |
| `high` (0.2.3 default for plan) | 15 seconds | ~640 tokens |

Ryter now always sends one: `high` for planning (the plan hat and the crew's architect), and `medium` for everything that acts (build, review, the lead, builders, auditors). I checked that DeepSeek, Grok, Claude, GLM, GPT, and Qwen models on OpenRouter all accept it. It's sent only to OpenRouter connections.

To change it, add this to `~/.ryter/config.toml`:

```toml
[reasoning_effort]
build = "high"      # low | medium | high | default (send nothing)
plan = "medium"
```

The roles are `build`, `plan`, `review`, `lead`, `architect`, `builder`, and `auditor`.
