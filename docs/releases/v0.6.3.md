## What changed

The crew screen had its board stacked above a full-width chat, which wasn't the layout the design showed. It is now:

```
  chat   changes ^t   crew board        lead deepseek-v4.1-flash · builders same · auditor glm-5.3-prime
╭ SPEND ──────────╮ ╭ TASKS ─────────╮ ╭ CHECKS ────────╮ ╭ ELAPSED ────────────╮
│ $0.063 of $3.00 │ │ 1 of 3 landed  │ │ ✓ cargo test   │ │ 0:29 · 22 calls     │
╭ PLAN ──────────────────────────────────╮ ╭ LANES ─────────────────────────────────╮
│ ┌──────────────┐    ┌──────────────┐   │ │ auditor  ⠋ greet  reviewing   0:07 $0.002 │
│ │ ✓ scaffold   │─┬─▶│ ◑ greet      │   │ │ builder  ⠋ count  cargo test  0:07 $0.045 │
│ └──────────────┘ │  └──────────────┘   │ ╭ LEAD ──────────────────────────────────╮
│                  └─▶┌──────────────┐   │ │ the lead's conversation                │
│                     │ ◐ count      │   │ │                                        │
│ legend  ✓ landed  ◐ building  …        │ │ › ask the lead; the crew does the work │
```

- **The plan is on the left, at full height,** with a legend at its foot.
- **The lanes, and the lead's conversation and prompt, are on the right,** in their own boxes.
- **The strip names who fills each seat** (lead, builders, auditor) and where the patch lands.
- **The tiles are SPEND, TASKS, CHECKS, and ELAPSED.** CHECKS shows what runs on every task and the patch. ELAPSED counts time, model calls, and retries.
- **Each lane shows what its task has cost so far.**
- **`tab` picks a lane, and `⏎` opens its transcript:** everything that worker said it was doing, as it happened. The bar also says `esc stop the crew` while the crew works.

## Fixed

- **A blocked task's reason was the audit's header** (`blocked: [z-ai/glm-5.3-prime · review]`). It's now the audit's first finding: `the audit failed it: src/app.rs is still absent`.
- **The patch counted a task as landed after it had been sent back for a retry.**

## Left out of the design, on purpose

- **Progress bars in the lanes.** There's no real measure of how far along a worker is, so any bar would be made up. Lanes show elapsed time and cost instead.
- **`p plan`.** Typing `p` starts a message.
- **Picking lanes with `↑↓`.** On an empty prompt those recall earlier messages, so lanes use `tab`.

## Tried before release

In the TUI at 120 columns, on a crew run in a new Rust project with a scaffold and two tasks after it:
- **Mid-run:** the plan drew `✓ scaffold` fanning out to greet and count, both `◑ in audit`. The lanes showed the two auditors with their costs, and `tab` picked a lane.
- **At the end:** all three landed. The lead's report sat in the LEAD box, and `cargo test` passed on the result.
