A reply that stops short no longer passes for a finished one, the audit keeps what you edited while it ran, a Claude model on OpenRouter keeps its reasoning through a tool call, and what Ryter writes on your disk now carries a schema number, with a kept copy of each release's files in the tests.

## Upgrade

```sh
ryter update
```

Coming from 0.42.0:

- **A dropped stream is an error.** A provider's stream that closed before the provider said the reply was over used to be read as finished: half an answer stood as the answer, and a half-written tool call ran. The turn now fails and says so, what arrived stays on the screen, and nothing of it reaches the conversation. A server that closes without `[DONE]` after giving its finish reason is fine, as before.
- **The audit keeps your edits.** The audit's rollback put back a file you edited in your editor while it ran, and reported that as the audit's change. Ryter now watches the tree around the audit's calls that can change it, MCP tools among them, and around your hooks wherever they fire: what changed while none ran is yours and stays as you left it, even where the audit or a hook wrote to the same file, and what the audit changed goes back from a checkpoint that `/redo` can restore until the next build turn. `/undo` after that `/redo` takes back the same files and leaves yours.
- **OpenRouter's reasoning goes back within a tool call.** `reasoning_details` were dropped, so a model through OpenRouter lost what it had reasoned at each tool call, where Anthropic's own connection keeps it. They now go back to the same model, within the running tool loop.
- **The project map's first line is `./ (name)`.** Written like a folder, it sent a model looking for `name/a.txt`; one then told the user the project's files were missing.
- **Project memory is shared out.** `ROADMAP.md`, `DECISIONS.md` and your notes each get a third of the 48 KB and pass on what they don't use, and a cut line says what was left out. A large roadmap used to fill it alone.
- **The gate no longer loses a command behind a quote or a `#`.** `echo ${f:-a #x}; rm -rf /` read the `#` as a comment, and `echo "${f:-"'"}"; rm -rf /; echo "'"` read the `rm` as quoted, so a second command went unjudged and the line passed. `${…}`, `$(…)` and backticks now have the quoting the shell gives them, in all three places the gate reads a command, and what stands between backticks is read as a line of its own. This was so in every earlier release. Where the sandbox is on, it still held what such a command could reach.
- **A `for` loop's values are read as the shell will.** `for f in a b; do sed -i … $f; done` is judged value by value, patterns and lists included, and `echo` and `printf` no longer ask because of a path in their text. `f[0]=x`, `f+=x`, `"${f}"`, `${f[0]}` and `${f[@]}` count as setting and reading `$f`, which they did not before, and an operator such as `${f#pre}` or `${f/a/b}` is judged as what bash makes of the value, quotes and arithmetic included; one Ryter can't work out asks. The text of `${f:-text}` is judged where the name may be unset, a word that comes to nothing leaves the next one the program (`$g rm -rf /` is judged as the `rm` it is if `g` is unset), and outside quotes a pattern in a value is a pattern: `g='.en*'; cat $g` is refused. Where a name is set under a loop or a branch, or something else can change it, every value the command gives it is judged and the strictest verdict holds: `A=notes.txt; if x; then A=/etc/hosts; fi; sed -i … $A` asks, where it used to pass as `notes.txt`. A value with a space in it is judged split as well as whole, for loops and for `F="a b"`.
- **A routing change applies whole or not at all.** A key gone since connecting used to leave the old rules live under a screen showing the new ones.
- **The screens say what is so.** `/budget` and the guide say the cap stops the next call, so the last can pass it by its own cost. `/context` calls a window nothing states assumed. `/sessions` and `ryter sessions` read as the rail does: `$0` for no calls, `$?.??` for nothing priced, `≥` for a total that leaves calls out, and no `$0.00` for a session that cost something.
- **`ryter doctor` says what the sandbox covers** and leaves, for the profile you are on.
- **As root, a listing that goes down the tree from above root's own folders is refused:** `sudo ls -R /etc`, `sudo find / -name x`, `sudo du -a /etc`. One level and a total (`sudo ls -la /etc`, `sudo du -sh /var`) are still a question.
- **MCP has limits.** A line can be 4 MiB from a client and 32 MiB from an outbound server, a listener serves 32 connections, and a TCP client has ten seconds to authenticate. A finished session now closes its socket: a refused client was left connected.
- **What Ryter keeps carries a schema number.** Sessions, spend records, `config.toml`, `settings.toml`, `routing.toml`, a new `.ryter/run.toml` and `.ryter/plan.md`. Nothing you have is rewritten for it, and a file with no number reads as it did. A file from a newer Ryter stops it, says so, and is left as it was. The guide's new section says what persists where.

## Why

These come from the second outside review of the code, against 0.42.0, and from the path to 1.0 written after it. Most are places where the screen said more than was so. The dropped stream and the map's first line were not in the review: they were found by replaying what providers really send, and by a live run on a second model.

## Good to know

- **Going back to 0.42.0.** Once this release has saved `routing.toml`, 0.42.0 can't read the file: it warns, ignores your rules, and replaces them if you save from `/provider`. Keep a copy if you may go back, and don't run both on one home.
- **OpenAI and SpaceXSI have had no live tool round trip through this harness.** Their wire is tested against a stand-in only. Anthropic and OpenRouter are proven on recordings of their own bytes, and `docs/provider-proof.md` keeps the dated record.
- **The reasoning echo is proven on two models**, `anthropic/claude-sonnet-4.6` and `deepseek/deepseek-v4.1-flash`. A provider that refuses it would show as a 400 naming `reasoning_details` on a tool round.
- A bare `$f` the gate can't read is still not judged as a path: `for f in $(cat list); do sed -i … $f; done` passes, and the sandbox is what holds it, and so does a value passed through a second variable (`B=$A; cat $B`). `$f.txt` and `$f/x` ask.
- During an audit, a command left running in the background, writing after its call has returned, reads as you; and what you edit while a card is up on one of the audit's own commands, or while a hook runs, reads as the audit's.
- `sudo find` from above root's folders is refused even with `-maxdepth 1`. `sudo ls -la` does that job.
- A Unix-socket MCP client has no time limit, and an idle one holds its place among the 32.
- `hats.toml`, `permissions.toml`, `hooks.toml`, `mcp.toml`, `trusted.json`, `reasoning.toml`, `review.toml` and `last.toml` carry no schema number.
- Open from earlier releases: the scout has no seat in `/models`; the live measurement of check rounds avoided; selecting with the mouse untried by a person; the bench on macOS; a real run on macOS; WSL2 by hand.

## Tried before release

The full local check and CI on every patch, Linux and macOS. Live on real models, by hand and dated in `docs/provider-proof.md`: tool round trips, parallel calls and truncation on `claude-opus-5-5` through Anthropic ($0.09, a thinking signature handed back and accepted), `anthropic/claude-sonnet-4.6` through OpenRouter ($0.08, the same through `reasoning_details`) and `deepseek/deepseek-v4.1-flash` through OpenRouter ($0.004); the Anthropic and Claude-on-OpenRouter recordings are kept and replayed in every test run, with cancellation and dropped streams cut from them. In the real TUI on the simulated provider: two dropped streams and the recovery after them, the audit's rollback with an edit made while it ran and with a hook writing during it, then `/redo` and `/undo` over it, `/context`, `/budget`, `/sessions` and `/doctor`. The gate's verdicts on 1,573 commands from real sessions, old gate against new: none changed. A session written by the real 0.42.0 listed, resumed and carried on, losing no field; a `settings.toml` from a newer Ryter stopped it with the file untouched.

Not tried: OpenAI and SpaceXSI live; the MCP limits against a real client or a real server (scripted ones only); the root listing rule under a real `sudo` (the gate's decisions only, as a session never authenticates); doctor's sandbox lines on macOS; your own existing sessions.
