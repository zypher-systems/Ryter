# Tasks solved per dollar: Opus 5.5 on Ryter, Claude Code and OpenCode (2026-10-22)

The ten bench tasks, given to three tools on the same model, `claude-opus-5-5`,
each in a fresh copy of the same project with the same brief, scored by the
hidden tests. Made with `bench/compare.py` as described in
[`bench/README.md`](../../bench/README.md); the table below is the run's
`RESULTS.md` as written.

Every tool solved every task, so the number that separates them is the cost.
Ryter did the ten for $0.73, OpenCode for $1.17, Claude Code for $2.42 by its
own estimate.

## What was compared

- **The same model by the same route.** Ryter's built-in `anthropic` connection
  and OpenCode's `anthropic` provider each used an Anthropic API key, so their
  costs are what Anthropic charged. Claude Code was signed in with a Claude
  subscription; it prices its own usage at list rates and reports that, so its
  figure is an estimate of what the API would have charged, not a bill, marked
  † in the table.
- **One prompt per task, no questions.** Each tool got one prompt: a scope
  paragraph (work only here, no installing, no network, no commit) and the
  task's brief, which names the check to pass. Ryter ran its build hat with
  `--always-approve` under the `workspace` sandbox; Claude Code ran with
  `--dangerously-skip-permissions`; OpenCode with `--auto`. Ryter also had the
  project's run file with the check; the others were told the command in the
  brief. Ryter's plan and audit hats were not part of this: the number is the
  cost of the same work, not of Ryter's flow.
- **Each tool as installed**, with its own settings. Claude Code loaded the
  user's global configuration as it does for any session, which is part of
  why its prompts are large: every task read about 72,000 cached tokens and
  wrote 20,000 more to the cache, against Ryter's prompt of 10,000 to 15,000
  tokens. OpenCode's prompts were about 40,000 cached tokens.
- **Ten tasks, one attempt each, 600 seconds allowed, none needed more than
  44.** The tasks are small: eight Python and one each of Rust and TypeScript
  among them, a bug fix, a rename, a flag, a feature across four modules, a
  parser with its errors. A current model solves them all, which is why this
  first run measures cost. Harder tasks are the next step.

## Observations

- Claude Code edited the project's visible test file on two tasks
  (`test_shop.py`, `test_pager.py`) besides the source. The hidden tests, which
  it never saw, still passed, so the work was right; the brief did not forbid
  touching the tests.
- Nothing timed out and no tool asked a question. All three left the project
  uncommitted, as the brief asked.
- A first pass earlier the same day had OpenCode solve nothing: it reads the
  `PWD` variable before asking the kernel for its directory, and the runner had
  passed its own. That was the runner's fault, fixed before this run. In that
  earlier pass OpenCode also ran the same model through OpenRouter and solved
  all ten for $1.13, close to the $1.17 by Anthropic's own route here.
